# Публикация CASE.PLACE SALARY в App Store — чек-лист

Всё, что нужно сделать один раз перед первой отправкой на ревью. Предполагается, что проект `ios/CasePlaceSalary.xcodeproj` открыт в Xcode 16+ на Mac.

## 1. Аккаунты и идентификаторы

- [ ] Платный аккаунт [Apple Developer Program](https://developer.apple.com/programs/).
- [ ] App ID = Bundle ID из Xcode (по умолчанию `ru.caseplace.salary`), capability **Sign in with Apple** включена.
- [ ] В App Store Connect создано приложение: имя **CASE.PLACE SALARY**, основной язык — русский, SKU любой.
- [ ] В Xcode: **Signing & Capabilities → Automatically manage signing**, выбрана Team.

## 2. Бэкенд

- [ ] Выполнены SQL-скрипты: `SUPABASE_SCHEMA.sql`, `SUPABASE_ULTRA.sql`, `TELEGRAM_SUPABASE.sql`, **`SUPABASE_ACCOUNT.sql`** (удаление аккаунта).
- [ ] Redirect URL `caseplace://auth-callback` добавлен в Supabase → Authentication → URL Configuration.
- [ ] Провайдеры Apple и Google включены (см. `ios/README_IOS.md`). Проверьте оба входа на реальном устройстве.
- [ ] Sign in with Apple **обязателен**, если есть любой другой сторонний вход (Google) — правило App Review 4.8. В проекте он есть.

## 3. Версия и сборка

- [ ] `MARKETING_VERSION` (например `1.0.0`) и `CURRENT_PROJECT_VERSION` (целое число, увеличивать при каждой загрузке) — в настройках таргета.
- [ ] Иконка: `Assets.xcassets/AppIcon` (1024×1024, без прозрачности) — уже сгенерирована; при желании замените на брендовую.
- [ ] Product → **Archive** (схема `CasePlaceSalary`, устройство *Any iOS Device*), затем **Distribute App → App Store Connect → Upload**.
- [ ] Дождитесь обработки сборки и пройдите вопрос Export Compliance — в `Info.plist` уже стоит `ITSAppUsesNonExemptEncryption = NO` (используется только HTTPS), поэтому вопрос не появится.

## 4. Страница приложения в App Store Connect

- [ ] Скриншоты: iPhone 6.9" (iPhone 16 Pro Max) и 6.5" (iPhone 11 Pro Max / Xs Max) — снимите в симуляторе (⌘S) экраны «Сегодня», «Календарь», «Статистика», «Финансы».
- [ ] Описание (черновик):

  > CASE.PLACE SALARY — личный кабинет сотрудника: смены по графику 2/2, упакованные чехлы и заработок в одном месте. Вносите количество чехлов за 10 секунд, смотрите доход за смену и месяц, прогноз к концу месяца и прогресс к цели. Финансы: счета, расходы по категориям с лимитами, регулярные платежи, долги и копилки. Данные синхронизируются с сайтом и Telegram-ботом. Вход через Apple, Google или email; можно пользоваться без аккаунта.

- [ ] Ключевые слова: `смены, зарплата, график 2/2, учёт, бюджет, расходы, копилка`.
- [ ] Категория: **Finance** (вторичная — Productivity).
- [ ] URL политики конфиденциальности: `https://andrey1904-dev.github.io/my-pay/privacy.html` (файл `privacy.html` в репозитории; опубликуйте GitHub Pages, если ещё не опубликованы).
- [ ] URL поддержки: `https://github.com/Andrey1904-dev/my-pay/issues` (или свой сайт/email).
- [ ] Возрастной рейтинг: ответить «нет» на все вопросы → 4+.

| --- | --- | --- | --- | --- |
| Email | да (при входе) | да | нет | функциональность приложения |
| Имя | да (по желанию) | да | нет | функциональность |
| User ID | да | да | нет | функциональность |

Трекинга нет, рекламных SDK нет. Provisional data: не используется.

## 6. Обязательные требования ревью, которые уже закрыты в коде

- Удаление аккаунта из приложения (Guideline 5.1.1(v)): «Ещё → Удалить аккаунт» вызывает RPC `delete_own_account`.
- Sign in with Apple рядом с Google (4.8).
- Полная работоспособность без аккаунта (нет обязательной регистрации для базовых функций).
- Ссылка на политику конфиденциальности на экране входа и в разделе «Ещё».
- Нет использования приватных API; манифест PrivacyInfo с причинами доступа к UserDefaults (CA92.1) и временным меткам файлов (C617.1).
- Экран запуска (`UILaunchScreen`), только портретная ориентация, поддержка тёмной темы и Dynamic Type для системных шрифтов.

## 7. Перед отправкой — прогон на устройстве

- [ ] Вход Apple → выход → повторный вход (имя сохраняется в профиле).
- [ ] Вход Google возвращает в приложение (если нет — проверьте Redirect URL в Supabase).
- [ ] Внести смену на iPhone → она появилась на сайте; изменить на сайте → потянуть экран вниз на iPhone.
- [ ] Выключить сеть, внести смену, включить сеть — данные ушли в облако («Ещё → Синхронизировано»).
- [ ] Резервная копия из iPhone импортируется на сайте и наоборот.
- [ ] Удаление аккаунта с кодом `1904` очищает данные и возвращает на экран входа.
