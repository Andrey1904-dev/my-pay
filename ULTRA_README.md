# MY PAY ULTRA v13

Что добавлено:
- финансовый центр: доход, расходы, свободный остаток, дневной бюджет, прогноз;
- финансовые цели с прогрессом и конфетти;
- категории расходов + аналитика;
- шаблоны смен;
- часы, премия/доплата и комментарий к смене;
- расчёт дохода в час;
- CSV экспорт для Excel / Numbers;
- JSON резервная копия теперь включает новые данные;
- светлая / тёмная / системная тема;
- восстановление последней удалённой смены;
- офлайн-очередь сохранения смен при потере интернета;
- исправленный Service Worker без ошибки Response.clone();
- PWA PNG-иконки 192/512;
- подготовлена облачная синхронизация новых функций через user_app_data.

## Обновление GitHub Pages
Загрузи содержимое папки проекта в корень репозитория `my-pay`, заменив старые файлы.

## Чтобы новые данные синхронизировались между устройствами
В Supabase открой SQL Editor и выполни файл `SUPABASE_ULTRA.sql` один раз.
Без этого файла приложение всё равно работает: новые функции сохраняются локально на устройстве, а существующие смены и настройки продолжают работать через текущие таблицы Supabase.
