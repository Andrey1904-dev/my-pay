# Моя зарплата — версия WOW

Мобильное приложение для расчёта зарплаты при графике 2/2.

## Расчёт

Обычная смена: **2150 ₽**  
Праздничная смена: **4050 ₽** (именно фиксированная сумма)  
Сделка: `чехлы × 7 ₽ × 20%`

Пример:
- 1000 чехлов = 1400 ₽ сделки
- обычная смена = 3550 ₽
- праздничная смена = 5450 ₽

## Что внутри

- красивый мобильный интерфейс;
- быстрый ввод +100 / +500 / +1000 / +5000;
- график 2/2;
- отдельный переключатель праздничной смены;
- календарь с отмеченными сменами;
- редактирование любой даты;
- статистика месяца;
- цель месяца и прогресс;
- история смен;
- резервная копия и восстановление;
- PWA: можно добавить на экран телефона как приложение;
- данные хранятся локально в браузере.

## GitHub Pages

Загрузи все файлы в корень репозитория и включи GitHub Pages для ветки `main`, папка `/ (root)`.


## Вход
Регистрация и вход выполняются по логину и паролю. Для этой схемы в Supabase нужно отключить обязательное подтверждение email: Authentication → Providers → Email → Confirm email = OFF. Email пользователю не показывается и не требуется.
