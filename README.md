# CASE.PLACE SALARY

Личный кабинет сотрудника **CASE.PLACE**: смены по графику 2/2, упакованные чехлы, заработок, личные финансы и синхронизация между вебом, iPhone и Telegram-ботом.

- **Лендинг:** [andrey1904-dev.github.io/my-pay](https://andrey1904-dev.github.io/my-pay/)
- **Веб-приложение (PWA):** [andrey1904-dev.github.io/my-pay/app.html](https://andrey1904-dev.github.io/my-pay/app.html)
- **Версия:** `V1.01` (`1.0.1`)

---

## Что внутри

| Экран | Возможности |
| --- | --- |
| **Сегодня** | Ввод чехлов (`+100 / +500 / +1000 / +1500`, шаг `±100`), переключатель праздничной смены, мгновенный пересчёт ставки и сделки, прогресс текущей смены (08:00–19:00 Екатеринбург) или дата ближайшей смены по графику 2/2, прогресс цели месяца. |
| **Календарь** | Сетка месяца с графиком 2/2 (два рабочих / два выходных от выбранной опорной даты), окно смены (чехлы, часы, премия, заметка, шаблоны быстрых смен), удаление с возможностью отменить действие, очистка месяца. |
| **Статистика** | Заработок за месяц, цель и остаток до цели, прогноз к концу месяца по оставшимся рабочим сменам, средняя и лучшая смена, серия смен, столбчатый график по сменам, сравнение месяцев за год, список смен с редактированием. |
| **Финансы** | Счета (карта, наличные, накопительный, кредитка) с автопересчётом баланса, операции (расход, доход, перевод между счетами), категории и месячные лимиты с индикацией превышения, регулярные платежи («Оплатил» создаёт расход и переносит дату), долги («я должен» / «мне должны» с частичным погашением), копилки с историей пополнений, расчёт ближайшего аванса (23-го за 1–15 число) и зарплаты (8-го за прошлый месяц минус аванс), финансовый советник. |
| **Ещё** | Аккаунт и облачная синхронизация (Email, Google, Apple), привязка Telegram-бота одноразовым кодом, настройки расчёта и графика, шаблоны смен, светлая / тёмная / системная тема, браузерные напоминания, экспорт и импорт резервной копии JSON, выгрузка смен в CSV, полное удаление аккаунта (`delete_own_account`). |

Приложение работает **офлайн-first**: все данные хранятся в `localStorage` и доступны без регистрации и без интернета (Service Worker `sw.js` кэширует лендинг и оболочку PWA). При входе в аккаунт данные синхронизируются с Supabase, а офлайн-изменения складываются в очередь и досылаются автоматически.

## Формула расчёта по умолчанию

Настройки меняются в разделе «Ещё → Настройки расчёта»:

- **Обычная ставка за смену:** `2 415 ₽` — `(выход 1 900 ₽ + обед 200 ₽) × 1,15` (районный коэффициент Екатеринбурга)
- **Праздничная ставка:** `4 600 ₽` — `(выход 3 800 ₽ + обед 200 ₽) × 1,15`
- **Сделка за чехол:** `7 ₽ × 25% = 1,75 ₽` (`1 750 ₽` за `1 000` чехлов)
- **Итог смены:** `ставка + чехлы × цена × процент + премия` (например, `1 000` чехлов в обычную смену = `4 165 ₽`, в праздничную = `6 350 ₽`)

## Быстрый старт и проверка

Требуется **Node.js ≥ 22.18**.

```bash
npm install
npm run check     # проверка синтаксиса script.js/sw.js, tsc --strict и все 103 теста
npm run build     # сборка лендинга и копирование ассетов в dist/ и корень
```

По отдельности:

```bash
npm test          # все 103 теста (лендинг + PWA + Telegram-бот)
npm run test:app  # только тесты веб-приложения (JSDOM)
npm run test:bot  # только тесты Telegram-бота
npm run typecheck # проверка типов TypeScript (strict)
npm run dev       # запуск Vite dev-сервера на http://0.0.0.0:5173
```

## Развёртывание бэкенда (Supabase)

Выполните SQL-скрипты в **Supabase SQL Editor** по порядку:

1. `SUPABASE_SCHEMA.sql` — таблицы `profiles`, `settings`, `shifts` и политики Row Level Security (`auth.uid() = user_id`).
2. `SUPABASE_ULTRA.sql` — таблица `user_app_data` для синхронизации финансов, счетов, лимитов, долгов и целей.
3. `TELEGRAM_SUPABASE.sql` — таблицы `telegram_links`, `telegram_link_codes`, `telegram_preferences`, `telegram_shift_actions`, `telegram_pending_Confirmations`, `telegram_bot_events` и RPC `create_telegram_link_code`.
4. `SUPABASE_ACCOUNT.sql` — функция `delete_own_account()` для удаления аккаунта из приложения.

Настройка и деплой Telegram-бота подробно описаны в [`telegram_bot_setup.md`](./telegram_bot_setup.md).
Инструкция по сборке iPhone-приложения в Xcode — в [`ios/README_IOS.md`](./ios/README_IOS.md) и [`APP_STORE.md`](./APP_STORE.md).
