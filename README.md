# Моя зарплата — Ultra v13

PWA для учёта смен, зарплаты, графика 2/2, личной финансовой аналитики, расходов и целей.

## Главное
- Supabase Auth + существующая синхронизация `profiles`, `settings`, `shifts`;
- календарь 2/2 и праздничные смены;
- прогноз дохода, графики, рекорды и цель месяца;
- расходы по категориям, свободный остаток и дневной бюджет;
- отдельные финансовые цели;
- шаблоны смен;
- часы, премии, комментарии и доход в час;
- JSON backup/restore и CSV для Excel/Numbers;
- тёмная/светлая/системная тема;
- восстановление последней удалённой смены;
- офлайн-очередь изменений;
- PWA + Service Worker v13.

Для облачной синхронизации расходов, целей, шаблонов и дополнительных полей один раз выполни `SUPABASE_ULTRA.sql` в Supabase SQL Editor. Основная авторизация и смены от этого файла не зависят.
