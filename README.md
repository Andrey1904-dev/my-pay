# CASE.PLACE SALARY

**CASE.PLACE SALARY** — личный кабинет для сотрудников CASE.PLACE: учёт смен, упаковки чехлов и заработка в одном удобном интерфейсе.

Приложение помогает быстро фиксировать количество упакованных чехлов, видеть доход за смену и месяц, планировать рабочие дни по графику 2/2 и пользоваться статистикой без лишних таблиц.

## Возможности

- учёт смен по календарю 2/2;
- быстрый ввод количества упакованных чехлов;
- расчёт оклада, сдельной части и общего дохода;
- статистика по сменам, чехлам и заработку;
- календарь рабочих и выходных дней;
- праздничная ставка;
- финансовый раздел и учёт расходов;
- цели по заработку;
- шаблоны смен;
- экспорт данных в CSV;
- резервное копирование и восстановление данных в JSON;
- тёмная и светлая темы;
- адаптивный интерфейс для телефона и компьютера;
- PWA-режим для установки на главный экран iPhone;
- Telegram-бот для внесения чехлов и просмотра текущего результата.

## Telegram-бот

Бот позволяет вносить упаковку прямо из Telegram, пользоваться быстрыми кнопками, смотреть историю добавлений и отменять последнее действие.

После добавления бот показывает:

- количество упакованных чехлов;
- мотивационное сообщение в зависимости от результата;
- заработок за смену;
- время до окончания рабочего дня.

Рабочее время в текущей логике: **08:00–19:00 по Екатеринбургу**.

## Запуск сайта

Проект не требует Node.js или отдельной сборки.

1. Загрузите файлы сайта в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. Выберите ветку `main` и корневую папку `/root`.
4. Сохраните настройки и дождитесь публикации GitHub Pages.

## Настройка Supabase

1. Создайте или откройте проект Supabase.
2. Выполните необходимые SQL-скрипты из проекта в SQL Editor.
3. Разверните Edge Function `telegram-mypay`.
4. Добавьте секреты функции в Supabase Secrets.

> Токен Telegram-бота нельзя хранить в GitHub, frontend-коде или SQL-файлах. Используйте только Supabase Secrets.

## Безопасность

- не публикуйте `TELEGRAM_BOT_TOKEN`;
- не добавляйте секреты в репозиторий;
- используйте Row Level Security в Supabase;
- перед публикацией проверьте настройки Auth и доступы к таблицам.

## Лицензия

Проект предназначен для внутреннего использования и может дорабатываться под рабочие процессы CASE.PLACE.
