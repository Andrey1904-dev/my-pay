# Моя зарплата — WOW

Мобильное PWA для учёта смен, чехлов и зарплаты при графике 2/2.

## Важные расчёты

- Обычная смена: **2150 ₽**
- Праздничная смена: **4050 ₽** — фиксированно
- Сделка: `чехлы × 7 ₽ × 20%`
- 1000 чехлов = 1400 ₽ сделки
- Обычная смена + 1000 чехлов = **3550 ₽**
- Праздничная смена + 1000 чехлов = **5450 ₽**

Сумма каждой сохранённой смены записывается в момент сохранения. Изменение ставок позже не пересчитывает историю.

## Авторизация

Пользователь видит только:

- Имя
- Логин
- Пароль
- Повтор пароля при регистрации

Email в интерфейсе отсутствует. Для Supabase Auth приложение использует технический детерминированный email, который пользователь не видит.

### Обязательная настройка Supabase один раз

В Supabase открой:

**Authentication → Providers → Email**

и включи Email Provider.

Для этой схемы установи:

- **Confirm email — OFF**
- обязательное подтверждение email не требуется.

Это необходимо именно для `signUp`: если Email Provider отключён, Supabase не позволит создать пользователя. Приложение теперь показывает конкретную причину вместо общего «Попробуй другой логин».

## База данных

Запусти `supabase_schema.sql` в **Supabase → SQL Editor → Run**.

SQL:

- создаёт `profiles`, `settings`, `shifts`;
- включает RLS;
- ограничивает чтение/изменение данными текущего `auth.uid()`;
- автоматически создаёт профиль и настройки после регистрации через Auth trigger;
- хранит фактические `base_pay`, `piece_pay`, `total_pay` каждой смены.
