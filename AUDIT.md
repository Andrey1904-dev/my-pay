## 1. Исправление бага с «чёрным окном вместо сайта»

### Выявленные причины
1. **Нескомпилированный `index.html` при раздаче из корня ветки `main` (GitHub Pages Legacy mode):**
   - Настройки GitHub Pages репозитория используют режим раздачи из корня ветки `main` (`build_type: "legacy"`, `source: main:/`), из-за чего системный пайплайн `pages-build-deployment` публиковал корневой `index.html` поверх артефактов Actions.
   - В корневом `index.html` находился пустой контейнер `<div id="root"></div>` с `<meta name="color-scheme" content="dark" />` (чёрный фон `#0b0c0e`) и ссылкой на нескомпилированный `<script type="module" src="/src/main.tsx"></script>`, который браузер не может загрузить и выполнить без Vite.
2. **Полноэкранный чёрный оверлей `Preloader` (`src/components/ui.tsx`, `src/App.tsx`):**
   - Компонент `Preloader` перекрывал весь экран чёрным слоем `fixed inset-0 z-[300] bg-ink` и блокировал прокрутку страницы (`document.documentElement.style.overflow = "hidden"`). Из-за передачи нестабильного колбэка `onDone={() => setLoading(false)}` в массив зависимостей `useEffect([onDone])` и особенностей `requestAnimationFrame` в фоновых вкладках / WebView / `prefers-reduced-motion` экран оставался чёрным.
3. **Затухание первого экрана в чёрный цвет при скролле (`src/components/Hero.tsx`):**
   - В `Hero.tsx` ко всему контейнеру первого экрана применялся `style={{ opacity: fade }}` (`useTransform(scrollYProgress, [0, 0.7], [1, 0])`). На мобильных экранах (где превью смартфона расположено под текстом) при прокрутке вниз весь контент первого экрана уходил в `opacity: 0`, оставляя пустое чёрное окно.
4. **Кэширование в Service Worker (`sw.js`):**
   - При переходе на `/privacy.html` навигационный обработчик `sw.js` перезаписывал ключ `./index.html` в кэше `my-pay-v1.01`, а при ошибке загрузки статических ресурсов возвращал `./index.html` вместо ассета.

### Что сделано
- **Двойная совместимость деплоя (корень репозитория + `dist/`):** `npm run build` компилирует лендинг в `landing.js` и `landing.css` (как в `dist/`, так и в корень репозитория), а `index.html` подключает `./landing.css?v=1.01` и `./landing.js?v=1.01`. В режиме разработки (`vite dev`) плагин `devLandingTransform` в `vite.config.ts` прозрачно подменяет вход на `/src/main.tsx`.
- **Мгновенный статический фолбэк в `index.html`:** внутри `<div id="root">` добавлена полноценная стартовая разметка первого экрана с рабочей кнопкой «Открыть приложение» (`./app.html`), поэтому страница видна с первой миллисекунды загрузки даже до инициализации JS.
- **Удалён `Preloader` и блокировка прокрутки:** лендинг рендерится сразу без искусственного чёрного экрана ожидания и без перехвата скролла библиотекой `Lenis`.
- **Убрано затухание `Hero` в чёрный при скролле и скрытие блоков (`opacity: 0`):** все секции лендинга отображаются сразу и остаются видимыми на любых мобильных экранах и в WebView.
- **Исправлен `sw.js`:** добавлены `./landing.css?v=1.01` и `./landing.js?v=1.01` в `APP_SHELL`, обновление кэша при установке выполняется с `{ cache: "no-cache" }`, разделены ключи кэша для `./index.html`, `./app.html` и `./privacy.html`.
- Добавлен `.nojekyll` в корень и `dist/` для отключения лишней обработки Jekyll на GitHub Pages.

## 2. Очистка от мусора и синхронизация кода

1. **Удалены лишние зависимости и мёртвый код:**
   - Из `package.json` и `package-lock.json` удалены неиспользуемые пакеты `lenis` и `vite-plugin-singlefile` (минус 8 пакетов в дереве зависимостей).
   - Из `src/components/ui.tsx` удалены `Preloader` и `Magnetic`.
   - Из `src/lib/pay.ts` удалена неиспользуемая функция `formatRubCompact`.
2. **Устранены дублирующиеся хэшированные артефакты сборки в `dist/`:**
   - Ранее Vite создавал в `dist/` дубликаты `manifest-*.webmanifest`, `icon-*.svg`, `icon-192-*.png` наряду с основными файлами. Теперь `dist/` содержит только чистый набор файлов без дублей.
3. **Актуализированы дефолтные значения тарифа в разметке и схеме БД:**
   - В `app.html` исправлены начальные подписи до инициализации скрипта: ставка `2 415 ₽` (вместо устаревших `2 627,84 ₽`), за 1 чехол `1,75 ₽` (вместо `1,69 ₽`), за 1 000 чехлов `1 750 ₽` (вместо `2 013 ₽`).
   - В `SUPABASE_SCHEMA.sql` дефолт `shifts.total_pay` обновлён с `2627.84` на `2415`.

## 3. Результаты автоматических проверок

Команда `npm run check` выполняет:
1. `node --check script.js && node --check sw.js` — синтаксическая проверка JS.
2. `tsc -p supabase/functions/tsconfig.json` — строгая проверка типов (`strict: true`) всех Edge Functions (`_shared/mypay.ts`, `telegram-mypay/bot.ts`, `telegram-reminders/reminders.ts`).
3. `tsc -p tsconfig.json` — строгая проверка типов (`strict: true`, `noUnusedLocals: true`, `noUnusedParameters: true`) всех компонентов лендинга `src/`.
4. `node --test tests/*.test.mjs` — **103 автоматических теста** (`42` в `tests/app.test.mjs`, `5` в `tests/site.test.mjs`, `56` в `tests/telegram-bot.test.mjs`), 0 ошибок.
